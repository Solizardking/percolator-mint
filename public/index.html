6 · Agent token: $CLAWD only


$CLAWD (8cHzQHUS2s2h8TzCmfqPKYiM4dSt4roa3n7MyRLApump, pump.fun) is the only token ever paired with any Percolator agent.
It is named in every agent's metadata (token field, a token service, and the tokens list below, with $CLAWD as primary).
Every agent minted here gets this list: the default URI is the v3 registration that carries it, and API mode sends it in agentMetadata. This console has no token-launch path.


tokens list written to every new agent


The on-chain agent-token slot (setAgentTokenV1) stays unset: the program only accepts a Genesis launch account that it minted itself
(GenesisAccountV2, funding mode Mint), and $CLAWD is a pump.fun Token-2022 mint with its mint authority revoked, so it can never qualify. Setting anything else would lock the agent to a non-$CLAWD token forever.
